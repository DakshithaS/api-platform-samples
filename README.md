# WSO2 API Platform Samples

Runnable samples for WSO2 API products. Each sample stands up a local stack,
demonstrates one capability, and tears itself down. No cloud account needed.

## Branches

One branch per product, so each evolves without breaking the other.

| Branch | Product |
| --- | --- |
| `main` | Bijira |
| `api-platform` | WSO2 API Platform (this branch) |

The histories are unrelated — `api-platform` is an orphan branch. Don't merge
between them.

## Structure

```
<gateway>/<capability>/<sample>/
```
